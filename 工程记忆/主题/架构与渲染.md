# 架构与渲染

应用基于 Vite、TypeScript、Three r149 与 GSAP。`ExperienceState` 统一协调加载、滚动、诗歌、全屏绘画、内容与 Restart 状态。

- 相机：真实内容高度驱动的 `7.5×` 滚动行程（用户定制偏离原站）；原始滚动触发纸片，受限阻尼滚动驱动相机，最大滞后为总进度 1.5%。桌面 100px 滚动约推进 0.36 秒镜头。
- 纸片：26 个 GLB 节点只作变换和射线代理；可见纸面使用共享的 10×10 细分实例平面、纹理图集与 SDF 边缘。所有层初始倒伏，按 `startAt` 并行触发用户定制的 3 秒立起、5 秒曲面舒展和 7 秒 `uRevealProgress: 0→15` 水彩生成。普通纸片保留源码四点 reveal 前沿；完整 dry-LUT 图集从归一化进度 0.18 后以二次 ease-out 追赶，并在第 6.5 秒锁定完成，因此中间态仍从 0 到 1 绘出，边缘又不会在中部完成后长期泛白。仅透明背景层继续完全使用源码 reveal 的颜色和 alpha。
- 水彩：每张纸按纸片与地面真实尺寸获得独立动态模拟区域；命中使用 GLB 真实形状代理和最近可见层规则。纸片坐标保留源码的两阶段 X 转换（射线命中时翻转、进入 `paperBox` 前翻回），地面使用独立的 Y 转换，避免纸片笔触左右镜像。`BrushSample` 同时携带前后中心、前后半径、标准化 NDC 速度和源码尺度；hover 按源码把速度 `[0, 0.08]` 映射到尺度 `[0.2, 1.8]`，小位移使用比例校正圆形，大位移使用不等径胶囊，切换纸片时清除连续性。流体按源码执行 external force → advection → divergence → pressure → gradient subtract → accumulation，`mouseForce=50`、`deceleration=0.98`、`attenuation=0.96`、`dt=0.008` 与 `intensity=0.06` 分开维护，并将逐帧系数换算为实际帧时长；旧位置约 3 秒平滑衰减。dry/ink LUT 令未交互区域低对比、交互区域显色，并由速度方向产生折射式 UV 扰动；不再使用持久颜料补偿。
- 地面与草：每个 `hasGround` 图层拥有独立地面实例和模拟映射。桌面草叶按源码固定密度 Poisson（1.8–2.8、7 次尝试）、椭圆簇、10 片图集、24 段渐变及 Perlin 风动生成；命中约 1 秒升起、约 3 秒回落，移动端不启用完整草实例。
- 阴影：24 个 `castShadow` 图层经 5×5 投影纸片、SDF 图集、源码方向光、spread/attenuation/skew 参数写入屏幕 RenderTarget；地面和背景合成接收该投影。
- 标题：从 GLB `titles` 节点读取六个场景标签，用本地 Canela MSDF 字体渲染，并可进入对应 Full Paint。
- 音频：`AudioManager` 以 Enter 点击作为解锁入口，统一维护静音偏好、页面可见性及 `loop-main`、`loop-poem`、`loop-painting` 主题；主题音量 1，交叉淡入淡出 0.8 秒。
- 尾部：原优势、订阅、礼物、FAQ 和页脚内容已按用户定制清空；保留空白内容插槽高度和 Restart。

代码入口集中在 `app/src/experience/`、`app/src/shaders/` 与 `app/src/config/`。验收约束见 [[主题/验收基线|验收基线]]。
