# 架构与渲染

应用基于 Vite、TypeScript、Three r149 与 GSAP。`ExperienceState` 统一协调加载、滚动、诗歌、全屏绘画、内容与 Restart 状态。

- 相机：真实内容高度驱动的 `2.5×` 滚动行程；原始滚动触发纸片，受限阻尼滚动驱动相机，最大滞后为总进度 1.5%。
- 纸片：26 个 GLB 节点只作变换和射线代理；可见纸面使用共享的 10×10 细分实例平面、纹理图集与 SDF 边缘。所有层初始倒伏，按原始时序立起、曲面舒展和显现。
- 水彩：纸片各自拥有流体图集区域；桌面 hover/press 使用连续胶囊笔触，移动端仅触摸拖动注入；减少动态效果时降级为静态可读内容。
- 标题：从 GLB `titles` 节点读取六个场景标签，用本地 Canela MSDF 字体渲染，并可进入对应 Full Paint。

代码入口集中在 `app/src/experience/`、`app/src/shaders/` 与 `app/src/config/`。验收约束见 [[主题/验收基线|验收基线]]。
